# NI Schools Map Assignment

This project creates an interactive map of schools in Northern Ireland using Python and Folium.
This project creates an interactive map of school locations across Northern Ireland. The aim is for the map to visually represent different types of schools and calculate the distance from a user defined location to each school.  The map will be created using Python within a Jupyter Notebook, utilising Folium.

## Features
- Displays school locations
- Calculates distance from a user-defined location
- Filters schools by type

## Requirements
- Python
- pandas
- folium
- geopy
